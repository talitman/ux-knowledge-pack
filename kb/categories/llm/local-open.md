## סינתזה

**תמונת מצב:** להריץ מקומית: Ollama [A0084](../../items/A0084.md) [A0376](../../items/A0376.md), WebLLM ו-Gemini Nano בדפדפן [A0056](../../items/A0056.md) [A0026](../../items/A0026.md), מודלים בטלפון [A0276](../../items/A0276.md), ו-AirLLM שמריץ מודל גדול שכבה אחרי שכבה [A0860](../../items/A0860.md) [A0966](../../items/A0966.md). מודלים קטנים ופתוחים: Gemma 4 [A0725](../../items/A0725.md), Qwen 2.5 Coder [A0008](../../items/A0008.md), Qwen 4 בדרך עם גרסת 27B למחשב הביתי [A1108](../../items/A1108.md), ו-fine-tune ל-gpt-oss [A0467](../../items/A0467.md).
**הגל הסיני:** במודלים open-weight שמתחרים בסגורים בקוד ובסוכנים. GLM-5.1 ו-GLM-5.2 של Z.ai ברישיון MIT [A0748](../../items/A0748.md) [A0939](../../items/A0939.md) [A0964](../../items/A0964.md), ו-Kimi K2.6 ו-K3 של Moonshot [A0874](../../items/A0874.md) [A0973](../../items/A0973.md), כולל "Agent OS" למעבר ביניהם [A0979](../../items/A0979.md). ⚠️ כותרות כמו "עוקף את Claude Code" צריך לבדוק בעצמכם [A1117](../../items/A1117.md).
**Gateways:** מחברים סוכני קוד לעשרות ספקים חינמיים או זולים עם fallback: OmniRoute [A0977](../../items/A0977.md), 9Router [A1014](../../items/A1014.md), NVIDIA build [A0705](../../items/A0705.md), ו-GLM ב-Claude Code [A0956](../../items/A0956.md). תצורה ארגונית מקומית: Hermes עם LiteLLM ו-Langfuse [A0898](../../items/A0898.md). ⚠️ בכל free tier צריך לבדוק פרטיות ותנאים.

**כלים בולטים בתת-הקטגוריה:** Ollama (7), Claude Code (4), GLM-5.2 (3), LM Studio (3), DeepSeek (3), Codex (2), Cursor (2), Cline (2), AirLLM (2), LiteLLM (2), Llama (2), Gemma (2)
