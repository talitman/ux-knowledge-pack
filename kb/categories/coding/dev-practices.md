## סינתזה

**תמונת מצב:** איך עובדים נכון עם סוכני קוד. השלב הראשון היה קבצי הנחיות ו-PRD (.cursorrules [A0130](../../items/A0130.md), Task Master [A0224](../../items/A0224.md), Spec Kit [A0513](../../items/A0513.md), PRD ל-vibe coding [A0372](../../items/A0372.md)). השלב הנוכחי הוא **Harness Engineering** [A0846](../../items/A0846.md): צוותי סוכנים (Agentic Squad [A0832](../../items/A0832.md), BMad [A0658](../../items/A0658.md)), harness מינימלי [A0766](../../items/A0766.md), ותזמור שלא תלוי בספק [A1051](../../items/A1051.md).
**נושאים חוזרים:**
- **וייב קודינג באחריות:** ארבעת העקרונות של חוקר Anthropic: להיות ה-PM של Claude, לעבוד על leaf nodes, לבנות יכולת אימות ולבדוק את התוצר [A0758](../../items/A0758.md). Uncle Bob לא קורא את הקוד אלא מכוון את הסוכנים מחצי צעד מעליו [A1058](../../items/A1058.md) [A1026](../../items/A1026.md).
- **לחשוב לפני שבונים:** grill-me [A0944](../../items/A0944.md), Claudex Loop, שבו מודל אחד מתכנן ואחר מאתגר [A1110](../../items/A1110.md), ו-Ponytail, "הסניור העצלן" שכותב 80–94% פחות קוד [A1016](../../items/A1016.md).
- **איכות ואבטחה:** review קפדני לארכיטקטורה [A0892](../../items/A0892.md), Strix ו-pentest עם סוכנים [A1035](../../items/A1035.md) [A1045](../../items/A1045.md), Aikido [A0698](../../items/A0698.md) [A0699](../../items/A0699.md), Codex Security מול Claude Security [A0656](../../items/A0656.md), ואבטחה בפרומפט למי שלא מתכנת [A0164](../../items/A0164.md).
- **בדיקות שהסוכן מריץ:** Playwright Agents [A0524](../../items/A0524.md), TestSprite [A0460](../../items/A0460.md) [A0584](../../items/A0584.md), ו-Codex כבודק QA [A0835](../../items/A0835.md).
- **תשתית לסוכנים במקביל:** worktrees [A1076](../../items/A1076.md), Stacked PRs [A1033](../../items/A1033.md), Slack Code [A1059](../../items/A1059.md), ו-GitHub Agentic Workflows [A0756](../../items/A0756.md).
- **מדידה עצמית:** AI Engineering Coach [A0852](../../items/A0852.md) [A0853](../../items/A0853.md) ו-Paxel, כולל אזהרת פרטיות [A0902](../../items/A0902.md).

**כלים בולטים בתת-הקטגוריה:** Claude Code (19), Cursor (14), Codex (10), GitHub Copilot (7), GitHub Actions (3), ChatGPT (3), OpenCode (3), VS Code (3), Lovable (3), TestSprite (3), Bolt.new (3), Docker (2)
