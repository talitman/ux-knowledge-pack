**תמונת מצב:** Cursor מופיע ב-100 פריטים. מסלול ההתפתחות שלו ממחיש את כל השוק: עורך עם AI [A0016](../../items/A0016.md) [A0198](../../items/A0198.md), background agents גם מהמובייל [A0316](../../items/A0316.md), Cursor 3 כפלטפורמת ניהול סוכנים [A0724](../../items/A0724.md) עם PR review [A0818](../../items/A0818.md) ו-/multitask [A0774](../../items/A0774.md), סוכנים תמידיים [A0651](../../items/A0651.md) [A0802](../../items/A0802.md), /orchestrate [A0811](../../items/A0811.md), Projects [A1095](../../items/A1095.md), ובסוף רכישה על ידי SpaceX [A1053](../../items/A1053.md). Codex הפך לאפליקציית דסקטופ עם computer use, ‏/goal ו-Sites [A0759](../../items/A0759.md) [A0796](../../items/A0796.md) [A0890](../../items/A0890.md), וכולל ייבוא מ-Claude Code [A1089](../../items/A1089.md). חלופות: Windsurf ו-Devin Desktop [A0009](../../items/A0009.md) [A0042](../../items/A0042.md), Antigravity [A0543](../../items/A0543.md) [A0854](../../items/A0854.md), Qoder [A0492](../../items/A0492.md) [A0507](../../items/A0507.md), TRAE [A0139](../../items/A0139.md), Copilot coding agent [A0248](../../items/A0248.md) [A0394](../../items/A0394.md), ו-Roo או Continue כקוד פתוח [A0237](../../items/A0237.md) [A0587](../../items/A0587.md).
**מגמות:** ממשקים חזותיים לסוכן (Design Mode [A0732](../../items/A0732.md) [A0897](../../items/A0897.md), תמונת רפרנס [A0851](../../items/A0851.md)), ניהול צבא סוכנים (Kanban [A0786](../../items/A0786.md), cmux [A0814](../../items/A0814.md), Herder [A0971](../../items/A0971.md)), ו-harness שלא תלוי במודל [A0947](../../items/A0947.md).
**איך Cursor מבין קוד:** chunks ו-Merkle tree בלי לשלוח את כל הקוד [A0442](../../items/A0442.md).
**מסקנה:** ההבדל בין הכלים כבר לא במודל אלא במעטפת ובאינטגרציות. כדאי לבחור stack ולא כלי בודד [A0854](../../items/A0854.md).
