## סינתזה

**תמונת מצב:** תת-הקטגוריה הגדולה במאגר (77 פריטים). Claude Code מופיע ב-213 פריטים ו-Codex ב-79. הגל החדש מאינסטגרם מראה עד כמה הכלי הפך לפלטפורמה:
- **ריצה ארוכה ואוטונומית:** Routines בענן לפי לוח זמנים, API או אירועי GitHub [A0751](../../items/A0751.md) [A0752](../../items/A0752.md), Dynamic Workflows ו-ultracode עם 100+ סוכנים [A0885](../../items/A0885.md) [A0905](../../items/A0905.md), ‏/goal ו-/loop [A0927](../../items/A0927.md) [A0862](../../items/A0862.md), Agent Teams עם רשימת משימות משותפת [A0702](../../items/A0702.md), ו-auto mode [A1042](../../items/A1042.md). חמשת הטיפים של בוריס צ'רני מסכמים את זה: auto mode, workflows, goal/loop, ענן, ובעיקר בדיקה עצמית [A0914](../../items/A0914.md).
- **אקוסיסטם של skills ו-plugins:** ספריית ה-plugins הרשמית [A1111](../../items/A1111.md), חבילות ענק כמו ECC (68 סוכנים ו-286 skills) [A1109](../../items/A1109.md) [A1091](../../items/A1091.md) [A1114](../../items/A1114.md), SuperClaude [A0681](../../items/A0681.md), GSD נגד context rot [A0560](../../items/A0560.md) וספריות של 380+ skills [A0712](../../items/A0712.md). skills לעיצוב אתרים (UI UX Pro Max ו-21st.dev [A0793](../../items/A0793.md), GSAP [A0794](../../items/A0794.md), Emil Kowalski, Impeccable ו-Taste [A1000](../../items/A1000.md) [A1104](../../items/A1104.md)).
- **חיסכון בטוקנים:** Caveman, תשובות קצרות שחוסכות 60–80% [A0734](../../items/A0734.md), ו-RTK שדוחס פלטי shell [A0772](../../items/A0772.md).
- **כלים משלימים:** עשרה כלי CLI במקום MCP (Playwright, GitHub, Vercel, Supabase, Stripe, FFmpeg) [A0703](../../items/A0703.md), Remote Control מהטלפון [A0626](../../items/A0626.md), בוט טלגרם עם ‏/loop [A0667](../../items/A0667.md), ו-Artifacts חיים [A0938](../../items/A0938.md). אלטרנטיבות ו-harnesses: OpenCode [A0633](../../items/A0633.md), Kimi Code [A0614](../../items/A0614.md), Happy [A0641](../../items/A0641.md), Warp [A0300](../../items/A0300.md) [A0504](../../items/A0504.md), Factory [A0612](../../items/A0612.md), ו-Claude Code עם מודלים מקומיים דרך Ollama [A0593](../../items/A0593.md).
**עקרונות חוזרים:**
- **אימות הוא הכל.** הטיפים של צ'רני [A0903](../../items/A0903.md) [A0914](../../items/A0914.md), ה-CLAUDE.md שלו [A1097](../../items/A1097.md), ‏/verify [A0998](../../items/A0998.md), ולולאת ולידציה ב-CLAUDE.md [A0654](../../items/A0654.md). סוכן בלי לולאת בדיקה סגורה מייצר שעות של תיקונים.
- **דעה שנייה ממודל אחר:** Codex כבודק או כפלאגין בתוך Claude Code [A0763](../../items/A0763.md) [A0776](../../items/A0776.md) [A0798](../../items/A0798.md), ו-Codex בונה ו-Claude סוקר [A0831](../../items/A0831.md).

- **לנקות מדי פעם:** למחוק כל חצי שנה את CLAUDE.md, ה-skills וה-hooks, ולהחזיר רק מה שבאמת חסר [A1038](../../items/A1038.md). למדוד skills עם ובלי [A1096](../../items/A1096.md) [A1098](../../items/A1098.md).
- **בידוד:** להריץ סוכן בלי הרשאות רק בתוך קונטיינר [A0996](../../items/A0996.md).
- **עלות:** gateways ומודלים זולים [A0634](../../items/A0634.md) [A0781](../../items/A0781.md) [A0956](../../items/A0956.md), והעברת סשן כשהמכסה נגמרת [A0791](../../items/A0791.md).
