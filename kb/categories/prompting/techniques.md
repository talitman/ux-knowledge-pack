## סינתזה

**מה השתנה:** טכניקות של 2024 מפנות מקום לעבודה עם מודלי reasoning. בין הטכניקות הישנות: ACDQ [A0079](../../items/A0079.md), Lyra ומטא-פרומפטים [A0367](../../items/A0367.md) [A0438](../../items/A0438.md) [A0107](../../items/A0107.md) [A0355](../../items/A0355.md), few-shot [A0733](../../items/A0733.md), Tree of Thought [A0180](../../items/A0180.md), והמבנה של ברוקמן [A0219](../../items/A0219.md). לפי המדריך של Anthropic ל-Opus 5.5, "תחשוב שלב אחרי שלב" כבר מיותר. מגדירים מה לעשות, איך נראה "סיימת" ומתי לעצור [A1115](../../items/A1115.md). אותו עיקרון במדריך ל-Astra [A1090](../../items/A1090.md) ובטיפים של OpenAI ל-GPT-5 [A0490](../../items/A0490.md).
**Reverse prompting:** "אתה מומחה" דווקא מוריד דיוק [A0709](../../items/A0709.md). עדיף לתת למודל לשאול אתכם שאלות ולמצוא blind spots [A1093](../../items/A1093.md) [A0800](../../items/A0800.md).
**טריקים שעובדים:** פלט HTML כ"סביבת חשיבה" והסבר חזותי (/eli5 [A1061](../../items/A1061.md), [A0872](../../items/A0872.md)), XML או Markdown במקום JSON [A0502](../../items/A0502.md), אילוצים מפורשים [A0607](../../items/A0607.md), הגדרות נגד חנפנות [A0565](../../items/A0565.md), humanizer עם 33 סימני כתיבת AI [A1034](../../items/A1034.md), ומאסטרקלאס הפרומפטים של Anthropic [A0779](../../items/A0779.md) [A0847](../../items/A0847.md). כלים רשמיים: Prompt Generator [A0384](../../items/A0384.md), Prompt Optimizer [A0489](../../items/A0489.md), וספריות לפי תפקיד [A0520](../../items/A0520.md) [A0525](../../items/A0525.md).
**⚠️ "קודים סודיים"** כמו L99 ו-/godmode [A0718](../../items/A0718.md) [A0778](../../items/A0778.md) הם לא פיצ'ר מתועד. זה פשוט פרומפט קצר, ואפשר לנסח אותו במפורש.

**כלים בולטים בתת-הקטגוריה:** ChatGPT (20), Claude (15), Claude Code (4), Financy (3), Anthropic Console (2), OpenAI Academy (2), GPT-5 (2), Cursor (2), Windsurf (2), Gemini (2), Claude Opus 5.5 (1), Codex (1)
