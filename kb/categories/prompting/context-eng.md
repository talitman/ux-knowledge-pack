## סינתזה

**התובנה המרכזית:** יותר הוראות זה לא בהכרח טוב יותר. Anthropic מחקו יותר מ-80% מהסיסטם פרומפט של Claude Code בלי ירידה בתוצאות [A1010](../../items/A1010.md). CLAUDE.md צריך להיות רזה ולהתמקד במלכודות הספציפיות. ה-CLAUDE.md של Karpathy מנוסח כארבעה עקרונות [A0764](../../items/A0764.md). "Harness" הוא כל מה שאינו המודל [A0826](../../items/A0826.md). סשנים ארוכים מרעילים את הקונטקסט [A0639](../../items/A0639.md). TOON חוסך כמחצית מהטוקנים לעומת JSON [A0642](../../items/A0642.md), ו-Context Mode חוסך עוד [A0671](../../items/A0671.md).
**לולאות במקום פרומפטים:** Loop Engineering: מבצעים, בודקים מול יעד שאפשר לאמת, וחוזרים [A1011](../../items/A1011.md). לפי צ'רני, ב-skill מגדירים קודם איך לבדוק [A1036](../../items/A1036.md) (ראו coding/claude-code).
**זיכרון:** סיכום שיחה למעבר לצ'אט חדש [A0095](../../items/A0095.md), MEMORY.md כאינדקס בזיכרון האוטומטי של Claude [A0896](../../items/A0896.md), מוח מבוסס קבצים בלי vector DB [A0974](../../items/A0974.md), Obsidian [A0863](../../items/A0863.md), זיכרון צוותי דרך proxy [A1032](../../items/A1032.md), ולוג יומי שהסוכן כותב [A1078](../../items/A1078.md).
**ללמוד מהטובים:** אוספי system prompts שדלפו [A0260](../../items/A0260.md) [A0332](../../items/A0332.md) והקוד הפתוח של Copilot Chat [A0363](../../items/A0363.md). בעברית: Skills IL, 154 skills לצרכים ישראליים [A0737](../../items/A0737.md).

**כלים בולטים בתת-הקטגוריה:** Claude Code (14), Codex (5), Cursor (5), ChatGPT (4), Lovable (2), Manus (2), GitHub (2), TencentDB Agent Memory (1), Hermes Agent (1), OpenClaw (1), Claude Cowork (1), Obsidian (1)
