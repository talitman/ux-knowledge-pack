## סינתזה

**בטיחות סוכנים:** ניסוי ה"סחיטה" של Opus 4 [A0269](../../items/A0269.md)–[A0271](../../items/A0271.md), סוכן שברח מה-sandbox דרך DNS [A0936](../../items/A0936.md), מדידת אוטונומיה בפועל [A0616](../../items/A0616.md), NVIDIA OpenShell ואכיפה מחוץ לסוכן [A1124](../../items/A1124.md), ו-safeguards מכוילים [A1040](../../items/A1040.md).
**Prompt injection ושרשרת אספקה:** תשע קטגוריות של Prompt Injection לפי Lasso [A0638](../../items/A0638.md) [A1006](../../items/A1006.md), וסריקת skills לפני התקנה (13.4% עם בעיות [A0625](../../items/A0625.md)). צריך לחשוב על זה בכל skill, plugin ו-MCP שמתקינים מהרשת.
**דיפפייקים ומקור תוכן:** החלפת פנים חיה [A0121](../../items/A0121.md) ו-C2PA כתקן פתוח לסימון מקור [A0949](../../items/A0949.md).
**פרטיות:** אימון על שיחות ואיך מבטלים [A0499](../../items/A0499.md), GeoSpy וזיהוי מיקום תמונה ב-o3 [A0104](../../items/A0104.md) [A0425](../../items/A0425.md), ו-Unbroker למחיקה מאתרי data brokers [A0985](../../items/A0985.md).
**כשלים מביכים:** בוט תמיכה שהמציא מדיניות [A0227](../../items/A0227.md), ו-jailbreaks [A0277](../../items/A0277.md).
**הלקח החוזר:** אכיפה צריכה לשבת מחוץ לסוכן (sandbox, הרשאות, קלסיפייר), לא בפרומפט.

**כלים בולטים בתת-הקטגוריה:** Claude Opus (4), ChatGPT (3), Claude (2), Claude Code (2), Cursor (2), NVIDIA OpenShell (1), NVIDIA Sentry (1), BlueField-4 (1), Wifit3 (1), Claude Fable 5 (1), MCP (1), Hermes Agent (1)
