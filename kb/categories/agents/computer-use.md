## סינתזה

**תמונת מצב:** סוכנים שמפעילים דפדפן ומחשב: Claude Computer Use [A0076](../../items/A0076.md) [A0077](../../items/A0077.md), browser-use [A0101](../../items/A0101.md), ChatGPT Agent (ניקוי Gmail [A0427](../../items/A0427.md), קופונים [A0428](../../items/A0428.md) [A0522](../../items/A0522.md), בדיקות E2E [A0420](../../items/A0420.md)), דפדפני AI (Comet [A0356](../../items/A0356.md) [A0509](../../items/A0509.md), Dia [A0366](../../items/A0366.md), Genspark [A0413](../../items/A0413.md)), Claude for Chrome [A0554](../../items/A0554.md), ו-Manus My Computer [A0684](../../items/A0684.md). בצד התשתית: OmniParser [A0134](../../items/A0134.md), Stagehand [A0214](../../items/A0214.md) ו-Obscura [A0787](../../items/A0787.md).
**הלקח המרכזי:** גלישה "כמו אדם" יקרה ושבירה. הפתרונות: לכתוב סקריפט אחד במקום קליק אחרי קליק (browser_exec ב-Hermes, 48–66% פחות טוקנים [A1044](../../items/A1044.md)), Playwright CLI במקום ה-MCP שלו [A0708](../../items/A0708.md), לחשוף API או JS מוכן [A0906](../../items/A0906.md), תצוגה קומפקטית [A1060](../../items/A1060.md), ו-API רשמי איפה שיש [A1002](../../items/A1002.md). את הדפדפן משאירים רק למקום שבו אין ברירה.
**לימוד מהדגמה:** Clips [A0928](../../items/A0928.md) ו-screenpipe [A1048](../../items/A1048.md).

**כלים בולטים בתת-הקטגוריה:** Claude Code (7), ChatGPT Agent (6), Codex (5), Comet (4), Cursor (2), Hermes Agent (2), Claude (2), Browserbase (2), Puppeteer (2), ChatGPT Atlas (2), Hugging Face (2), Perplexity (2)
