## סינתזה

**תמונת מצב:** מוצרי סוכנים אוטונומיים: ChatGPT Agent [A0379](../../items/A0379.md) [A0387](../../items/A0387.md) [A0431](../../items/A0431.md), Genspark Super Agent [A0250](../../items/A0250.md), Claude Cowork [A0621](../../items/A0621.md), ו-Manus [A0683](../../items/A0683.md) (כולל שכפול פתוח [A1081](../../items/A1081.md)). ב-2026 שלטו **OpenClaw ו-Hermes** [A0573](../../items/A0573.md) [A0597](../../items/A0597.md) [A0797](../../items/A0797.md) [A0868](../../items/A0868.md) [A0894](../../items/A0894.md) [A0922](../../items/A0922.md), וסביבם נוצרה שורה של חלופות: PokeeClaw המנוהל [A0731](../../items/A0731.md), NanoClaw המאובטח ב-sandbox [A1037](../../items/A1037.md), cortextOS על Claude Code [A0878](../../items/A0878.md), ו-OpenClaw על Raspberry Pi [A0754](../../items/A0754.md). במקביל עלו פלטפורמות שמשלבות אנשים וסוכנים (Buzz [A1020](../../items/A1020.md) [A1025](../../items/A1025.md) [A1028](../../items/A1028.md), Slack [A1056](../../items/A1056.md), Cabinet [A0795](../../items/A0795.md)).
**מגמה: סוכן עם מחשב משלו,** שרץ גם כשהלפטופ סגור: Grok Bot [A1046](../../items/A1046.md) [A1079](../../items/A1079.md) [A1105](../../items/A1105.md), Perplexity Personal Computer [A0665](../../items/A0665.md), Claude Routines [A0817](../../items/A0817.md), Claude Managed Agents [A1054](../../items/A1054.md), ו-Mac Mini שדולק 24/7 [A0921](../../items/A0921.md) [A0562](../../items/A0562.md).
**דפוס ארגוני:** לא 15 בוטים נפרדים אלא היררכיה של "מנהלי מחלקות" שמאצילים לסוכנים [A1120](../../items/A1120.md), וסוכנים פנימיים, למשל HR ופיננסים ב-Slack [A0820](../../items/A0820.md).
**סיכונים:** הסוכן יורש את ההרשאות של מי שהתחבר. כדאי משתמש ייעודי, sandbox, הפרדת סביבות ואישור אנושי לפעולות רגישות [A1046](../../items/A1046.md) [A1037](../../items/A1037.md).

**כלים בולטים בתת-הקטגוריה:** Claude Code (9), Codex (7), OpenClaw (7), Hermes Agent (7), Grok Bot (5), Slack (5), Telegram (5), Claude (4), Notion (3), Manus (3), Buzz (3), Gmail (3)
