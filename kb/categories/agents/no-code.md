## סינתזה

**תמונת מצב:** n8n הוא הכלי המרכזי: self-host ב-$5 או בדקה ב-Hostinger [A0178](../../items/A0178.md) [A0256](../../items/A0256.md), בוט WhatsApp [A0241](../../items/A0241.md) [A0408](../../items/A0408.md), סוכן GPT-5 בדקה [A0468](../../items/A0468.md), ושיחות מכירה קרות עם VAPI [A0462](../../items/A0462.md). לצידו Make ו-Lindy [A0441](../../items/A0441.md) [A0466](../../items/A0466.md), Pipedream ו-String [A0320](../../items/A0320.md) [A0333](../../items/A0333.md), Google Opal [A0471](../../items/A0471.md) [A0498](../../items/A0498.md) [A0531](../../items/A0531.md), Dify [A0726](../../items/A0726.md) ו-Sim [A0650](../../items/A0650.md).
**המגמה: ה-AI כותב את האוטומציה.** Gemini כותב JSON של workflow שלם ממשפט אחד [A0555](../../items/A0555.md), מסרטון YouTube ל-workflow [A0577](../../items/A0577.md), n8n-MCP בתוך Claude Code [A0637](../../items/A0637.md), ואלפי תבניות מוכנות [A0571](../../items/A0571.md). השלב הבא: מדגימים במקום מגדירים. מקליטים את המסך ומקבלים skill [A0990](../../items/A0990.md) [A0928](../../items/A0928.md), או בונים סוכן מייל ב-Claude Code רק עם connectors ו-CLAUDE.md [A0955](../../items/A0955.md).
**ביקורת:** דניס נרוש עבר מ-n8n ו-Make לקוד עם Cursor [A0280](../../items/A0280.md) [A0360](../../items/A0360.md). כשהלוגיקה מסתבכת, קוד שסוכן כותב גמיש יותר מתרשים.

**כלים בולטים בתת-הקטגוריה:** n8n (20), Google Opal (7), Gmail (5), Google Sheets (4), Google AI Studio (3), Claude (3), WhatsApp (3), Make (3), Pipedream (3), Claude Desktop (2), Claude Code (2), Slack (2)
