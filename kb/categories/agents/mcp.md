## סינתזה

**תמונת מצב:** MCP הוא "USB לסוכנים", ופותר את בעיית N×M [A0154](../../items/A0154.md). MCP מול A2A [A0209](../../items/A0209.md) [A0405](../../items/A0405.md). במאגר יש קטלוגים [A0167](../../items/A0167.md) [A0199](../../items/A0199.md) [A0232](../../items/A0232.md), שרתים רשמיים (GitHub [A0202](../../items/A0202.md) [A0210](../../items/A0210.md), Chrome DevTools [A0515](../../items/A0515.md) [A0517](../../items/A0517.md) [A1083](../../items/A1083.md), Google Workspace [A0648](../../items/A0648.md) [A0790](../../items/A0790.md), Meta Ads [A0941](../../items/A0941.md)), ובנייה מהירה (Postman Generator [A0521](../../items/A0521.md), Databutton [A0203](../../items/A0203.md), משאבים למתחילים [A0449](../../items/A0449.md)).
**שרתים שחוזרים בהמלצות:** Context7 לדוקומנטציה עדכנית [A0396](../../items/A0396.md), Firecrawl לרשת [A0600](../../items/A0600.md) [A0917](../../items/A0917.md), DeepWiki ו-Octocode להבנת ריפו [A0416](../../items/A0416.md) [A0850](../../items/A0850.md), 21st.dev Magic ל-UI [A0691](../../items/A0691.md), Excalidraw לדיאגרמות [A0660](../../items/A0660.md), NotebookLM למחקר [A0631](../../items/A0631.md) [A0867](../../items/A0867.md), wigolo לחיפוש מקומי [A1072](../../items/A1072.md), ו-PAL לשילוב כמה מודלים [A1068](../../items/A1068.md).
**Skills ו-Plugins לצד MCP:** "MCP הוא הצינור, Skills הם המתכון". Claude Skills [A0529](../../items/A0529.md) [A0533](../../items/A0533.md) [A0591](../../items/A0591.md), Plugins לפי תפקיד [A0672](../../items/A0672.md), ו-Cowork plugins [A0623](../../items/A0623.md). MCP Apps מחזירים UI אינטראקטיבי [A0644](../../items/A0644.md).
**הפרוטוקול התבגר:** Desktop Extensions [A0304](../../items/A0304.md), OAuth ו-Tunnels [A1021](../../items/A1021.md), וגרסת יולי 2026, שהיא stateless ובלי session [A1027](../../items/A1027.md).
**הגל הבא: WebMCP** [A0598](../../items/A0598.md) [A1065](../../items/A1065.md) [A1075](../../items/A1075.md) [A0906](../../items/A0906.md).
**אזהרות:** אבטחת שרתים ו-skills [A0670](../../items/A0670.md), ניפוח הקונטקסט ממספר כלים (gateway [A0828](../../items/A0828.md) ו-CLI במקום MCP [A0799](../../items/A0799.md) [A0703](../../items/A0703.md)), ו-prompt injection דרך כלים [A1006](../../items/A1006.md).

**כלים בולטים בתת-הקטגוריה:** MCP (19), Cursor (12), Claude (12), Claude Desktop (9), Claude Code (8), Claude Skills (4), Chrome DevTools MCP (3), WebMCP (3), Gemini (3), Firecrawl (3), NotebookLM (3), Windsurf (3)
