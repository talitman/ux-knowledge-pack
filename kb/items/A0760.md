## סיכום

- **ארכיטקטורה:** VS Code ו-Electron, multi-process. קריסת **renderer** חמורה ביותר (העורך וחלון הסוכנים). קריסת extension בדרך כלל מתאוששת.
- **Observability:** כל קריסה מדווחת עם process, סוג, מכשיר, minidump ו-stack. מדדים per-session (כמה נפגעים) ו-per-request (חומרה).
- **Debugging:**
  1. **Top-down:** feature flag ו-A/B, למדוד את התרומה לזיכרון.
  2. **Bottom-up:** ניתוח דליפות ו-hot paths.
- **Guardrails:** בדיקות רגרסיה לפני שחרור. תיקונים upstream ל-Electron ול-VS Code.
- **הקשר:** subagents, instant grep ו-browser use מעמיסים על הזיכרון.
