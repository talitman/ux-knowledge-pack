## סיכום

- **שימוש ב-web** ([repomix.com](https://repomix.com), לפי צילום המסך ששלח Dotan):
  1. מדביקים URL של GitHub (או `user/repo`), או מעלים תיקייה או zip.
  2. **Output format:** XML (ברירת מחדל), Markdown או Plain.
  3. **Include/Ignore patterns** (glob): למשל `src/**/*.ts` או `**/*.test.ts,README.md`.
  4. אפשרויות: Include File Summary, Directory Structure, Line Numbers, Parsable Format.
  5. עיבוד: **Compress Code** (שלד בלבד בעזרת tree-sitter), Remove Comments, Remove Empty Lines.
  6. Pack, והורדה או העתקה.
- **CLI:** `npx repomix` בתיקיית הפרויקט.
- **עוד:** [MCP server](https://repomix.com/guide/mcp-server), GitHub Actions, בדיקת אבטחה (Secretlint) לסודות.
- **חלופות:** Gitingest ([A0234](A0234.md)), uithub ([A0054](A0054.md)).
- **רישיון:** open source (MIT).
