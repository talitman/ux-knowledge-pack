  - **Playground:** דף לכל endpoint.
  - **Build:** Docs, Status, Pricing.
- **שלבים:**

  2. נכנסים ל-[platform](https://ideogram.ai/platform).
  3. מוסיפים אמצעי תשלום וקרדיטים.
  4. יוצרים API key.
