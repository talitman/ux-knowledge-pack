## סיכום

- **שלוש רמות:** local, repo, organizational catalog.
- **find_skills:** מקבל משימה ומחזיר 0 או יותר skills, בחיפוש וקטורי בשני אזורים.
- **עדכונים:** checksum מזהה skills מקומיים מיושנים.
- **סטנדרט:** SEP-2640 (Skills כ-MCP resources, PR פתוח בזמן הפוסט).
- **תוצאה:** "דיוק גבוה בחיפוש בכל שלוש הרמות".

**מהתמלול / מהווידאו:**
- **מהפריימים (דיאגרמת הארכיטקטורה):** **Agent** (MCP client) קורא ל-**find_skills** ב-MCP Gateway, שמבצע **Semantic Search** (textual + embeddings) מול **Catalog Vector DB** (shared catalog index) ומחזיר **Skill Result** (resource_uri). ה-client קורא את ה-SKILL.md ומזריק לקונטקסט. במסלול נוסף: Install Skill ו-Local Skill, עם **Runtime Skill Index** (input, local). **Developer** מפרסם skill ל-Catalog (GitHub), שמתעדכן ב-vector DB.
