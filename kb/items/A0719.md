## סיכום

- **הרכיבים:**
  - **תמונות:** Nano Banana. חינם, בלי watermark, עריכת רקע וטקסט עברי.
  - **וידאו:** Veo 3.1, 8 שניות, אופקי או אנכי, image-to-video.
  - **Remotion:** וידאו כקוד. לחנות עם 50 מוצרים, "שעה במקום שבוע".
  - **דפי נחיתה:** HTML ו-CSS רספונסיביים, מהטרמינל לפרודקשן.
  - **ניוזלטר:** תוכן שבועי ל-HTML.
- **Skills:** כותבים פעם אחת. מי שיש לו Claude Code יכול להשתמש בלי לתכנת.
- הסרטון (15 דקות) לא נותח כאן. הסיכום מבוסס על הפוסט.

**מהתמלול / מהווידאו:**
- **מהתמלול (אלירון ג'יני, מייסד ו-CTO של Open Finance):** "אם אתם עדיין משלמים לפרילנסרים על כל באנר, סרטון קצר או דף נחיתה, תפסיקו". פרילנסרים מצוינים למשימות יצירתיות ומורכבות, אבל **כ-80% מהעבודה השיווקית היומיומית** Claude Code עושה לבד: תמונות, סרטונים קצרים, דפי נחיתה וניוזלטרים, מהטרמינל ומאפליקציית Claude Code. כמעט כל התוכן בערוץ שלו עובר דרך Claude Code.
- **ניוזלטר:** Claude אוסף ידיעות וממיין אותן לפי פורמט: כותרת חזקה, 3–5 נקודות תוכן ותקציר לכל אחת. בסוף מוסיפים Remotion: מקוד React, תבנית אחת יכולה להפיק 100 סרטונים.
