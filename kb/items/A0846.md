## סיכום

- **"Give Codex a map, not a 1,000-page manual":** AGENTS.md גדול נכשל:
  - קונטקסט הוא משאב נדיר.
  - כשהכל "חשוב", שום דבר לא חשוב.
  - נרקב מיד.
  - קשה לאמת.
- **Knowledge base:**
  - `docs/` מובנה: design docs עם סטטוס אימות, architecture map, quality grades לכל domain.
  - **execution plans** עם progress ו-decision logs בריפו.
  - linters בודקים freshness ו-cross-links.
  - **doc-gardening agent** פותח PRs לתיקון מסמכים מיושנים.
- **"מה שהסוכן לא רואה בקונטקסט, לא קיים":** הכל בריפו.
- **Legibility:**
  - האפליקציה עולה per git worktree.
  - Chrome DevTools Protocol ו-skills ל-DOM, screenshots ו-navigation.
  - logs, metrics ו-traces במחסנית ephemeral לכל worktree.
- **ארכיטקטורה:** שכבות קבועות. Cross-cutting (auth, telemetry, flags) דרך Providers בלבד. custom lints ל-structured logging, naming וגודל קבצים: "constraints allow speed without decay".
- **Loop:** Codex סוקר את עצמו, מבקש agent reviews מקומיים ובענן, ומגיב עד שכולם מרוצים (Ralph Wiggum Loop). ריצות של יותר מ-6 שעות.
- **Golden principles ו-GC:** פעם 20% מהשבוע הלכו לניקוי "AI slop" ביום שישי. היום משימות רקע סורקות סטיות, מעדכנות ציונים ופותחות refactor PRs שנבדקים בפחות מדקה. "Human taste captured once, enforced continuously".
- **כשמשהו נכשל:** לא "try harder" אלא "what capability is missing, and how do we make it legible and enforceable?"
