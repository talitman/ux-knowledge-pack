## סיכום

- **צוות הנדסה:** gstack של Garry Tan (`git clone ... garrytan/gstack ~/.claude/skills/gstack && ./setup`); Superpowers (`/plugin marketplace add obra/superpowers`); Codex (`npm i -g @openai/codex`); Frontend Design, Skill Creator ו-MCP Builder מ-anthropics/skills; Agent Browser (`npx skills add vercel-labs/agent-browser`).
- **שיווק:** marketingskills (`coreyhaines31/marketingskills`, עם `--skill social` לרשתות), claude-seo (`AgriciDaniel/claude-seo`), humanizer (`blader/humanizer`), HyperFrames (`GIT_LFS_SKIP_SMUDGE=1 npx skills add heygen-com/hyperframes`).
- **Connectors:** Slack, Notion, Zapier, Granola, Perplexity, Higgsfield (`claude mcp add --transport http --scope user higgsfield https://mcp.higgsfield.ai/mcp`).
- **תעשייה:** Claude for Financial Services ו-Claude for Legal.
- **ליבה:** anthropics/skills, Find Skills (`npx skills search`), Caveman (`JuliusBrussee/caveman`, לפי המדריך חותך כ-65% מהפלט), ו-"Kondo" כלומר /compact, /clear וקובץ זיכרון.
- **טעויות נפוצות:** להתקין את כל ה-24 בבת אחת, להתקין כלים לא מוכרים, לשכוח Node.js 18+, ולתת לצ'אטים להתנפח.
- **סדר מומלץ:** יום 1 הליבה, יום 2 אפליקציה אחת, יום 3 כלי שמכניס כסף.
