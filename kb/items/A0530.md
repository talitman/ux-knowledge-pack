## סיכום

- **מה זה:** "custom onboarding materials" שאורזים מומחיות. למשל עבודה עם Excel, או הנחיות המותג של הארגון. כך Claude יוצר קבצי xlsx, pptx, docx ו-pdf באפליקציות.
- **איך עובד:** במהלך משימה Claude סורק את ה-skills הזמינים (שם ותיאור). כשיש התאמה הוא **טוען רק את המינימום**, וזה שומר על מהירות.
- **תכונות:**
  - **Composable:** skills מצטרפים, ו-Claude מתאם ביניהם.
  - **Portable:** אותו פורמט ב-Claude apps, ב-**Claude Code** וב-**API**.
  - **Efficient:** נטען רק מה שצריך.
  - **Powerful:** קוד הרצה למשימות שבהן תכנות אמין יותר מיצירת טוקנים.
- **עדכון (18.12.2025):** ניהול skills ארגוני, directory של skills משותפים, ו-**Agent Skills כסטנדרט פתוח** ([agentskills.io](https://agentskills.io)).
- ⚠️ **אבטחה:** skills מריצים קוד, אז רק ממקורות מהימנים.
- **משאבים:** [engineering blog](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills), [docs](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview), cookbook.
- **מבנה בסיסי:**
```text
my-skill/
  SKILL.md        # frontmatter: name, description  + הוראות
  scripts/...     # קוד אופציונלי
  resources/...   # תבניות, דוגמאות
```
