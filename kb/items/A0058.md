## סיכום

- **הרעיון:** "One codebase. Every role". כולם עובדים מאותו source of truth, בתוך הקוד ובתוך המותג, בלי handoffs.
- **workflow:** המפתח כותב את החלקים הקשים (ב-Builder או בכלי AI אחר) ודוחף branch. מעצבים, PMs ו-QA מלטשים פיקסלים, עורכים טקסט ומריצים בדיקות **באפליקציה האמיתית**. כל שינוי משתמש בקוד וב-design system הקיימים.
- **שימושים:** prototypes, web apps, landing pages. Builder Agent עובד בשבילך. (בעבר: Visual Copilot, Figma לקוד.)
- **Enterprise:** SOC 2 Type II. לקוחות כמו Zapier.
