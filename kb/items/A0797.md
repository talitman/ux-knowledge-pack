## סיכום

- **OpenClaw, Gateway-First:**
  - תהליך מתמיד בין משתמשים לסוכנים.
  - multi-agent routing עם הרשאות לכל סוכן.
  - **SOUL.md**: פרסונה, אילוצים ומטרות.
  - ההימור: הבעיה הקשה היא ניתוב ובקרה.
- **Hermes, Learning-First:**
  - Python native, ו-agent loop שאפשר לבדוק.
  - זיכרון: הערות, היסטוריה ב-SQLite וידע פרוצדורלי.
  - בונה מודל של ההעדפות שלך לאורך זמן.
  - ההימור: הבעיה הקשה היא זיכרון ושיפור עצמי.
- **שילוב:** OpenClaw כמתזמר, Hermes כמבצע, דרך פרוטוקול ACP.

**מהתמלול / מהווידאו:**
- **מהתמלול:** שני הפרויקטים פותרים אותה בעיה, "סוכן שזוכר אתכם ולא מתאפס בכל סשן". OpenClaw הוא "שוטר תנועה" (Gateway) עם 345k כוכבים, "הפרויקט הכי גדול בקטגוריית AI". Hermes שם את התהליך הקוגניטיבי במרכז: אחרי משימה מורכבת הוא עוצר, מנתח את הצעדים ויוצר skills חדשים. "OpenClaw מתחבר לכל מקום, Hermes לומד מעצמו". שניהם חינמיים.
