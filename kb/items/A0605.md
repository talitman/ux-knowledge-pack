## סיכום

- **הלולאה:**
  1. Run.
  2. Monitor logs. אם יש שגיאות, תקן והרץ מחדש.
  3. Analyze: זמן, טוקנים, $.
  4. Optimize לפי אסטרטגיות שכתובות בטקסט.
  5. Repeat עד plateau.
- **האסטרטגיות (bullets ב-prompt):**
  - system prompts קצרים.
  - הסרת הוראות כפולות.
  - פחות turns.
  - batching ו-early termination.
  - חיפוש ברשת של agentic patterns.
- **תוצאות:**

| מדד | לפני (Sonnet 4.5) | אחרי (Gemini 2.5 Flash) |
|---|---|---|
| זמן | 600–800 שניות | 169.5 שניות |
| עלות | $3–5 | $0.12 |
| טוקנים | מיליונים | 300,729 |

- **9 שינויים** שהסוכן מצא לבד. בין השאר: החלפת מודל, דחיסת `CODING_INSTRUCTIONS`, `TASK_PROMPT` ו-`CONTINUATION_PROMPT`, והוספת כלי `Write()`.
- **ללא** gradient descent, grid search או reward model. "Just an LLM reading logs and rewriting source files".
- קוד פתוח: [github.com/ksenxx/kiss_ai](https://github.com/ksenxx/kiss_ai).
