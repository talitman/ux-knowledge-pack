## סיכום

- **מה זה:** "High-Performance In-Browser LLM Inference Engine". הכל רץ אצל המשתמש בדפדפן עם האצת **WebGPU**: אין שרת, יש פרטיות ואין עלות inference.
- **פיצ'רים:**
  - **API תואם OpenAI** (chat completions, streaming, JSON mode, function calling חלקי).
  - תמיכה במודלים פתוחים רבים (Llama, Phi, Gemma, Mistral, Qwen) ומודלים מותאמים בפורמט MLC.
  - Web Workers / Service Workers כדי לא לחסום את ה-UI. אפשר לבנות תוסף Chrome.
  - חבילת npm `@mlc-ai/web-llm`. דמו: WebLLM Chat.
- **נתונים:** Apache-2.0, TypeScript, ~19.3k כוכבים, פעיל (push באוקטובר 2026). יש paper ב-arXiv (2412.15803).
