## סיכום

- **Gemini CLI:** "looks, feels, acts exactly like Claude Code CLI".
  - **כמעט חינם:** עד 60 בקשות בדקה ו-1,000 ביום.
  - MCPs (למשל Context7 לדוקומנטציה), Memories ו-rules, ו-Tools כולל **Google search** מובנה.
- **Setup לריבוי סוכנים:**
  - `git worktree add` יוצר תיקייה נפרדת לכל סוכן (cursor / gemini / claude-code) על אותו ריפו.
  - תוסף **Peacock** צובע כל חלון VS Code בצבע אחר כדי לא להתבלבל.
- **המבחן:** אותו פרומפט ותמונה: אתר Next.js עם בלוג ודפי פוסט דינמיים.
- **Cursor Background Agents:** מ-cursor.com (dashboard). יוצרים feature branch, Sonnet Max, ו-PR workflow.
- **תוצאות:**
  - 🥇 **Cursor local agent:** העיצוב הכי מלוטש, היחיד שבאמת השתמש ב-shadcn שהיה מותקן.
  - 🥈 (תיקו) **Claude Code** (checklists נוחים למעקב) ו-**Cursor background agent**.
  - אחרון: **Gemini CLI**. שגיאות, rate limits ו-CLI "rough around the edges". "יש פוטנציאל, עוד לא שם".
- **מסקנה:** Cursor בגלל צפייה ועריכה של הקוד בזמן אמת ו-background agents. Claude Code ממשיך לבצע מצוין.

**מהתמלול / מהווידאו:**
- **מהתמלול (תוספות):**
  - **התקנה:** Node.js 18 ומעלה, פקודת npm אחת, ו-`gemini`.
  - **התחברות:** עם Gmail רגיל מקבלים הכי הרבה חינם, ולכן לא מומלץ מפתח API. אפשר גם Workspace.
  - **פקודות:** `/help`, `/editor` (העדפת IDE), `/stats`, `/mcp`, `/memory`, `/tools`. Esc מבטל פעולה, ו-@ מוסיף קבצים לקונטקסט.
  - **הערכה:** "85–90% ממה ש-Claude Code מציע", אבל Claude Code בשל ויציב יותר. היו בעיות rate limit.
  - **ה-setup שלו:** Cursor עם Claude Code בטרמינל. Claude Code לריבוי סוכנים ול-plan mode, ו-Cursor בגלל background agents מ-Slack ו-PRs ("מקבל הרבה מ-$20 לחודש").
