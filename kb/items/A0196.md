## סיכום

- **מה בנה:** MCP server ל-RAG על מסמכים "אמיתיים" ומורכבים: טקסט, תרשימי זרימה, תמונות וטבלאות.
- **סטאק:** **Cursor** כ-MCP client. **GroundX** של EyeLevel.ai בתוך ה-MCP server לעיבוד ושליפה.
- **איך זה עובד:**
  1. המשתמש מדבר עם Cursor.
  2. ה-client מתחבר לשרת ובוחר tool (search או ingest).
  3. ה-tool משתמש ב-GroundX לחיפוש מתקדם.
  4. התוצאות משמשות ליצירת התשובה.
- **יכולות:** חיפוש ושליפה במסמכים, **ingest** של מסמך חדש לפי path מהצ'אט. קוד בתגובות. אפשר לבדוק את GroundX על מסמכים שלכם ב-eyelevel.ai.
