## סיכום

- **התקנה:** `npm install -g oh-my-codex` (Node 20 ומעלה), לצד Codex CLI.
- **Workflows:** כל אחד עצמאי, בלי שרשרת קבועה:
  - `$plan`
  - `$ultragoal`
  - `$team` (צוות סוכנים)
  - `$code-review`
  - `$ultraqa`
- **State:** תיקיית `.omx/` עם guidance, plans ו-logs.
- **אזהרה:** Windows native ו-Codex App פחות נתמכים.
- **דומה ל:** oh-my-claudecode של אותו יוצר. יש גם גרסה רזה יותר (gajae-code).
