## סיכום

- **Connect:** תשתית אינטגרציה לסוכנים.
  - **Managed auth** (OAuth): טוקנים מוצפנים לפי פרויקט, לא חשופים לאפליקציה, וביטול חשבון בקריאת API אחת.
  - יותר מ-10,000 tools ו-triggers מוכנים, ו-raw proxy לכל השאר.
- **Conduit** (early access): gateway מאובטח לכלי ה-AI שהחברה משתמשת בהם.
- **מחיר:** חינם בפיתוח, בלי כרטיס אשראי. משלמים במעבר ל-production.
