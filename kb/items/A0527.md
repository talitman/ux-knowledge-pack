## סיכום

- **מה זה:** [nanochat](https://github.com/karpathy/nanochat). Pipeline מלא: tokenizer, pretraining, midtraining, SFT, RL אופציונלי, inference ו-web UI.
- **עלויות ותוצאות:**
  - **$100**, כ-4 שעות על 8×H100: צ'אטבוט בסיסי.
  - כ-12 שעות: עוקף את GPT-2 במדדים.
  - **$1,000**, כ-42 שעות: עקבי יותר, פותר קוד ומתמטיקה פשוטים.
- **המטרה:** בסיס איכותי ללמידה ול-forks, לא תחרות ב-OpenAI ("LLMs דורשים מיליונים").
- **האירוניה:** כ-8,000 שורות **נכתבו ביד** עם tab-autocomplete. Claude Code ו-Codex "just didn't work well enough... net unhelpful". Vibe coding מתאים לפרויקטים קטנים.
- **ללמידה:** חומר מצוין להבנת אימון LLM מקצה לקצה. ראו [A0286](A0286.md).
