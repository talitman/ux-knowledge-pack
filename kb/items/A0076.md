## סיכום

- **ההודעה של Dotan:** "claude computer use".
- **מה זה:** client toolset שמוגדר ע"י Anthropic. היום הוא `{"type": "computer_toolset_20260801"}` ב-`tools`, ונותן ל-Claude **17 כלים**: `screenshot`, `left_click`, `type`, `zoom` ועוד, לאינטראקציה אוטונומית עם desktop.
- **איך זה עובד:** האפליקציה שלך מריצה את הסביבה (VM/container עם desktop). Claude מבקש פעולה, אתה מבצע ומחזיר screenshot, וחוזר חלילה (agent loop).
- **כלים משלימים:** Bash tool, Text editor tool, Browser use tool (למשימות שנשארות בדפדפן), parallel tool use, prompt caching.
- **בטיחות:** לבודד בסביבה וירטואלית, להיזהר מ-prompt injection שמגיע מתוכן על המסך, ולא לתת גישה לחשבונות רגישים.
- **תאימות (בדף היום):** מודלי Claude העדכניים (Opus, Sonnet ועוד), וגם Claude Platform on AWS.
