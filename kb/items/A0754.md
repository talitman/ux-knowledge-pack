## סיכום

- **Stack:** Raspberry Pi, OpenClaw (סוכן אישי פתוח), ממשק Telegram.
- **התקנה:** Claude Desktop ביצע הכל (computer use או טרמינל).
- **יכולות:** קוד, אוטומציות, זיכרון, API discovery, עריכת וידאו, ואופי מוגדר.
- **המסר:** חומרה זולה מספיקה לשימוש ביתי.
- ⚠️ אבטחה (רקע): לסוכן עם גישה מלאה מומלץ sandbox (NemoClaw, [A0685](A0685.md)).

**מהתמלול / מהווידאו:**
- **מהתמלול:** החיבור נעשה דרך יכולת ה-**SSH** (חיבור מרוחק) של Claude Desktop, שמוסברת בקורס של יובל (practical.yuv.ai). מרגע ההתקנה הוא מדבר עם הבוט בטלגרם, והבוט שולט במערכת ההפעלה של ה-Raspberry Pi **בסביבה מבודדת**. "אחד הדברים הכי מדהימים שעשיתי".
