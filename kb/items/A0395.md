## סיכום

- **Setup:**
  1. מתקינים את תוסף Chrome של Browser MCP.
  2. מוסיפים את השרת ל-`mcp.json` ב-Cursor (לפי הדוקומנטציה).
  3. Connect בתוסף.
- **דמו 1:** "go to the ... documentation page and save it as API docs txt". נווט, צילם ושמר. חוסך זמן באיסוף docs לפרויקט.
- **דמו 2:** בדיקת אפליקציה מקומית (שדה טקסט ושיר). הסוכן לוחץ ומקליד, אבל **האפליקציה התאפסה** שוב ושוב ולא עבד עד הסוף.
- **יתרון:** עובד בדפדפן האמיתי שלך, עם לוגינים. מקומי ופרטי.
- **השוואה:** Playwright MCP, Stagehand ([A0214](A0214.md)).
