## סיכום

- **הבסיס:** ReAct agent מהשיעור הקודם, עם **Tavily** לחיפוש ברשת ו-LLM של **Anthropic**.
- **מה מוסיפים:** **checkpointer** של LangGraph על **PostgreSQL** (`AsyncPostgresSaver`). כל state של השיחה נשמר ב-DB לפי `thread_id`.
- **שלבים:**
  1. מקימים PostgreSQL (מקומי/ענן) ו-connection string.
  2. מתקינים `langgraph-checkpoint-postgres` ו-`psycopg`.
  3. `async with AsyncPostgresSaver.from_conn_string(DB_URI) as checkpointer: await checkpointer.setup()`.
  4. מעבירים את ה-checkpointer ל-`create_react_agent(model, tools, checkpointer=checkpointer)`.
  5. קוראים לאייג'נט עם `config={"configurable": {"thread_id": "..."}}`.
- **תוצאה:** האייג'נט זוכר הודעות קודמות גם אחרי restart. רואים את הטבלאות ב-**pgAdmin**.
- **רקע:** ReAct (arXiv 2210.03629). המטרה לא לקודד במקביל אלא להבין את הקונספט.
