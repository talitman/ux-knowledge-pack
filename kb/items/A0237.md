## סיכום

- **Roo Code:** הרחבת AI coder חינמית ל-VS Code (fork של Cline). משלמים רק על ה-API של המודל.
- **השלבים:**
  1. מתקינים [VS Code](https://code.visualstudio.com/) (חינם).
  2. Extensions, מחפשים Roo Code ומתקינים.
  3. מגדירים provider: [OpenRouter](https://openrouter.ai/) (גישה להרבה מודלים במפתח אחד) או OpenAI.
  4. בוחרים **mode** (Code / Architect / Ask וכו') וכותבים פרומפט: "build a time tracking app".
  5. Roo מתכנן, יוצר קבצים, מריץ פקודות (באישור) ומציג.
  6. בודקים ומשפרים באיטרציות.
- **למי:** מתחילים שרוצים "Cursor חינמי" עם שליטה על המודל.
