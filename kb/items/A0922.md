- **מהתמלול (יובל אבידני):** Hermes יכול להיות עוזר אישי שרץ על WhatsApp או Telegram (כמו OpenClaw), מחובר לכלים ומבצע פעולות. הוא גם יכול לעבוד כמו Claude Code בטרמינל. ההתקנה לא עברה חלק, אז יובל פתח את Claude Code וביקש: "אני מנסה להתקין את Hermes", ו-Claude Code פתר את הבעיות. **המסר:** להבין את שני אופני השימוש, ולא לבלבל עם "צ'אטבוט נוסף".
