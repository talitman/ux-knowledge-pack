## סיכום

- **הטענה:** Qwen2.5 Coder הוא מודל open source של 32B פרמטרים שעוקף את GPT-4o ואת DeepSeek בקוד (לפי benchmarks, Aider leaderboard).
- **איך מקבלים אותו בחינם:** באתר **glhf.chat** פותחים new chat ומדביקים קישור למודל מ-Hugging Face. ל-API: Account → API settings, ושם מקבלים base URL ו-API key. ה-API **תואם OpenAI**.
- **חיבור ל-Aider (שלבים):**
  1. להגדיר `OPENAI_API_BASE` ל-`https://glhf.chat/api/openai/v1`.
  2. שם המודל חייב להתחיל ב-`openai/` (מוסכמה של LiteLLM) ואחריו `hf:` ושם הריפו ב-HF.
  3. לטעון את המודל (לוקח זמן "להתעורר") ולהריץ.
- **הסתייגות של היוצר:** מצוין במשימות קטנות. ספק אם הוא מחזיק codebases גדולים כמו המודלים הסגורים.
- תגיות שהוזכרו: Cursor, Windsurf, Cline.
