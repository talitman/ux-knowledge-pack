## סיכום

- **הבעיה:** יום ראשון הוא קסם. אחר כך הסוכן מתחיל להזות פונקציות והמבנה מתפורר.
- **פקודות:**
  - `sentrux` (GUI treemap)
  - `sentrux check .` (CI, exit 0 או 1)
  - `sentrux gate --save .` לפני, ו-`sentrux gate .` אחרי, לזיהוי הידרדרות.
- **MCP:** `/plugin marketplace add sentrux/sentrux` ב-Claude Code, או config ל-Cursor, OpenCode ו-OpenClaw.
- **Rules engine** לחוקי ארכיטקטורה.
- **דמו:** Opus 4.6 בונה FastAPI, והציון נעצר ב-6772 בלי חיישן.
