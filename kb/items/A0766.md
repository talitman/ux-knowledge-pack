## סיכום

- **מערכה 1, pi:**
  - בעיות ב-Claude Code: flicker ו-renderer, system prompt ו-tool definitions שמשתנים, ושינויי קונטקסט "מאחורי הגב".
  - OpenCode: באג אבטחה (CORS פתוח לכל אתר).
  - Terminal-Bench: harness מינימלי עם tmux keystrokes מצליח, אז מינימליזם עובד.
  - **pi:** שליטה מלאה בקונטקסט. Extensions הם TypeScript modules שמגדירים tools, slash commands, events ו-state.
- **מערכה 2, OSS בעידן הסוכנים:** pi הפך לליבה של OpenClaw, והגיע מבול issues ו-PRs אוטומטיים. פתרונות: אימות (vouch), תיוג, הורדת עדיפות, embedding של issues ל-3D, וסגירת tracker כשצריך.
- **מערכה 3, "Slow down":**
  - "100% built by agents. Yes, we know, it sucks."
  - מי שלא קורא קוד לא יוכל לתקן, והסוכנים מוצפים בקוד ענק.
  - "Long context windows are a hack."
  - הבנת המערכת ולמידה דורשות משמעת ו-agency אנושית.
