## סיכום

- **מה זה:** "Give agents knowledge". פלטפורמת ידע (Database, Nexus, Marketplace) לשליפה מהירה ומדויקת. לטענתם יותר מ-10,000 לקוחות ומיליון מפתחים.
- **שימוש:** API key אחד. search, upsert ו-rerank מאותו אינדקס. אפשר להתקין plugin באייג'נט:
  ```bash
  claude plugin install pinecone   # דורש גישה ל-Anthropic marketplace
  /pinecone:quickstart             # בתוך Claude Code
  ```
- **Enterprise:** SSO, RBAC, CMEK, private networking. SOC 2 Type II, HIPAA, GDPR, ISO 27001.
- **מחיר:** אינדקס ראשון חינם, אחר כך pay-as-you-go. יש מחשבון עלויות באתר.
