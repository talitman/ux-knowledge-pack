## סיכום

- **למה צריך כלי צד שלישי:** חסימות בוטים מקשות על סקרייפינג.
- **5 יכולות:** Scrape (דף), **Map** (גילוי כל ה-URLs), Search, **Crawl** (מעבר על הרבה דפים), **Extract** (דאטה מובנה). יש גם צילומי מסך ו-branding.
- **התקנה:** API key מ-firecrawl.dev, הוספת Firecrawl MCP ל-Claude Code (`claude mcp add ...`). שמירת cheat sheet בקובץ קונטקסט לפרויקט, כדי שלא יאבד בין סשנים.
- **Use cases:**
  1. **מודעות מתחרים:** סוג (וידאו או טקסט), מסרים וניתוח.
  2. **Brand guidelines:** צבעים, פונטים ו-vibe מאתר קיים, ואז פרומפט ל-IDE: "recreate a website... similar in look".
- **מחיר (רקע):** tier חינמי עם קרדיטים, ואחר כך מנוי.
