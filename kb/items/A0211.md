## סיכום

- **שני שלבים:**
  1. "מאמנים" מודל RAG על הנתונים: DDL, תיעוד, דוגמאות של שאלה+SQL.
  2. שואלים בשפה טבעית ומקבלים SQL שאפשר להריץ אוטומטית על ה-DB.
- **פיצ'רים:** דיוק גבוה בדאטאסטים מורכבים. **לומד מעצמו** (משתפר עם כל query נכון). מאובטח, הנתונים לא יוצאים מהסביבה. כל SQL DB (Snowflake, Redshift, Postgres...). ממשקים: Jupyter, Streamlit, Slack, Flask.
- **מהסרטון:** `pip install vanna`. Vanna ממיר שאלה ל-SQL, מריץ ומחזיר **טבלה, גרף ושאלות המשך**.
- **רישיון:** open source (MIT).
