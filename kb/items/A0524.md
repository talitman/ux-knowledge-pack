## סיכום

- **3 הסוכנים (לפי הדוקומנטציה):**
  1. 🎭 **Planner:** נכנס לאפליקציה, סורק ובונה **תוכנית טסטים ב-Markdown**.
  2. 🎭 **Generator:** ממיר את התוכנית לקבצי **Playwright Test** (מבצע כל צעד ומאמת selectors).
  3. 🎭 **Healer:** מריץ, מזהה כשלים, עוצר (debug) לבדוק מה קורה, ו**מתקן עד שעובר**.
- **התקנה:** `npx playwright init-agents --loop=vscode` (או claude / opencode). ב-VS Code נוצרים 3 chat modes, ב-Claude Code נוצרים subagents.
- **תובנה:** להפיץ סוכנים ו-subagents בארגון דרך CLI. לכל כלי יש FrontMatter ייחודי לקבצי הסוכן, שלא מתורגם ישירות בין סביבות.
