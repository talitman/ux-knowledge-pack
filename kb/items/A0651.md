## סיכום

- **למה:** "מצאנו את עצמנו מפעילים סוכנים שוב ושוב לאותה משימה".
- **Use cases:**
  1. **Incident triage:** טריגר PagerDuty, ו-Datadog MCP מוצא root cause ומכין PR. "אני רק ממרג' וחוזר לישון".
  2. **Nightly cron:** ניקוי dead code ודפוסים רעים ב-PRs מהיום האחרון.
  3. **Feature requests** מ-Twitter ל-Slack, ואז סוכן מעלה PR. פשוטים מיושמים אסינכרונית.
  4. Review וניהול של עומס הקוד הגדל.
- **התאמה:** גם הגדרות כמו "לסגור הערות קודמות" נכתבות כפרומפט ולא כ-checkbox.
