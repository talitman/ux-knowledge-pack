## סיכום

- **Dotan כתב:** "firecrawl".
- **מה זה:** **Open Lovable** (github.com/firecrawl/open-lovable). Firecrawl מגרד את האתר, LLM בונה אפליקציית React, וזה רץ בסנדבוקס (E2B/Vercel).
- **השימוש:** "clone and recreate any website as a modern React app".
- **רישיון:** קוד פתוח (MIT). צריך API keys של Firecrawl ושל המודל.

**מהתמלול / מהווידאו:**
- **מהפריימים (סרטון בלי דיבור):** בממשק Open Lovable מדביקים URL (כאן האתר של Firecrawl). מופיעים השלבים "Gathering website information", "Generating code" ועץ קבצי React (components/Hero.jsx, Pricing.jsx וכו'). אחר כך נטען שכפול של דף הבית ("WEB SCRAPING FOR DEVS & AGENTS") עם טבלת המחירים, ואפשר להמשיך לשנות בצ'אט (למשל "make the hero big animating"). התצוגה רצה ב-sandbox.
