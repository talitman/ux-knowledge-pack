## סיכום

1. **[RAGFlow](https://github.com/infiniflow/ragflow):** מנוע RAG להבנה עמוקה של מסמכים מורכבים, עם ציטוטים מבוססים. multimodal, web search ו-deep research. Open source, יותר מ-59k כוכבים.
2. **xpander:** backend framework-agnostic לסוכנים: memory, tools, multi-user state, events, guardrails. בונים, בודקים ופורסים בעיקר מה-UI. תואם LlamaIndex ו-CrewAI.
3. **Transformer Lab:** אפליקציה לניסויים: אימון, fine-tune, צ'אט, הורדת מודלים בלחיצה (DeepSeek, Gemma), RAG ב-drag-n-drop ו-logging. Open source ומקומי.
4. **LLaMA-Factory:** fine-tuning של יותר מ-100 LLMs/VLMs ב-UI בלי קוד (LoRA, QLoRA ועוד).
5. **Langflow** (כנראה): builder ויזואלי ל-agents ו-RAG.
6. **AutoAgent:** framework בלי קוד לבנייה ופריסה של סוכנים בשפה טבעית. תומך בכל LLM, Vector DB שמנהל את עצמו, function-calling ו-ReAct. כ-5k כוכבים.
- ביחד יותר מ-200k כוכבים.
