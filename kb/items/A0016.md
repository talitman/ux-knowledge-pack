## סיכום

- **ההודעה של Dotan (סטאק הסדנה, נובמבר 2024):**
  - **Cursor:** "עורך קוד עם בינה מלאכותית שמשמש לכתיבת קוד, עזרה, עריכה, יצירת קבצים ועריכת קבצים".
  - **v0:** עיצוב מקצועי לאתר/מערכת/אפליקציה ([A0015](A0015.md)).
  - **Bolt:** יוצר את הפרויקט: מתקין ספריות, מסדר את המבנה ומכין שלד שעובד ([A0017](A0017.md)).
  - **shadcn:** UI מקצועי ([A0018](A0018.md)).
  - **Supabase:** backend ([A0019](A0019.md)).
- **Cursor היום (לפי האתר):** "your coding agent for building ambitious software". יש Cursor Desktop ו-Cursor CLI, אייג'נטים שעובדים במקביל שעות וימים (Cloud Agents, כולל Canvases ו-Environments). לטענתם יותר ממחצית ה-Fortune 500 משתמשים בו.
- **ה-workflow המומלץ:** לעצב ב-v0, לייצר שלד ב-Bolt, להמשיך לפתח ב-Cursor, ולחבר Supabase ל-DB ול-auth.
