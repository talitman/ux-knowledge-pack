- **למה זה מעניין:**
  - **כל מודל:** GPT-5, Claude, Llama ועוד.
  - **מסמכים מורכבים:** טבלאות ותמונות (deep document understanding).
  - **ציטוטים** ישירים למקור, "בלי המצאות".
  - **Docker** ו-API ברור.
  - **GraphRAG**.
  - **Agentic:** query rewriting, web search, code sandbox.
  - קוד פתוח, בשליטה מלאה.
- **מסקנה:** כל ארגון יכול להרים POC של צ'אטבוט על מסמכים. ראו [A0323](A0323.md).
- **התקנה:** `git clone https://github.com/infiniflow/ragflow && cd docker && docker compose up -d`.
