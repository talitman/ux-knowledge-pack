## סיכום

- **מה זה:** "A curated list of awesome Model Context Protocol (MCP) servers". ~96.5k כוכבים, ~17.8k forks, MIT, מתעדכן כל הזמן.
- **הגדרה:** "MCP is an open protocol that enables AI models to securely interact with local and remote resources through standardized server implementations."
- **מבנה:** קטגוריות (Aggregators, Browser automation, Databases, Developer tools, Finance, Search, Media...). ליד כל שרת אייקונים: שפה (🐍 Python, 📇 TS), local (🏠) או cloud (☁️), ומערכות הפעלה.
- **Tips & Tricks:** איך לבקש מ-Claude להשתמש בשרתים. קישורים ל-Discord ו-r/mcp.
- **שימוש:** המקום הראשון לחפש בו שרת לפני שבונים אחד.
