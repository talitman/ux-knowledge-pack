## סיכום

- **Dotan כתב:** "Clude code".
- **לפי התיאור:** "a crystal clear explanation on what makes Claude Code different than Cursor, Codex and Windsurf". שיחה עם @rasmic על הלוח. בפרק הבא הוא אמור לבנות אפליקציה מאפס.
- **ההבדלים המקובלים (רקע, לא מהוידאו):** Claude Code רץ בטרמינל, agentic-first, עם context מלא של הריפו, subagents, hooks ו-CLAUDE.md, ובמחיר מנוי קבוע (Max). Cursor הוא IDE עם השלמות ו-Agent.

**מהתמלול / מהווידאו:**
- **התזה (מהתמלול):**
  - **המודל לבדו "חסר תועלת":** הוא לא יכול לקרוא קובץ. כל IDE מספק לו tools (קריאה וכתיבה לקבצים). האופן שבו הכלים בנויים ועובדים יחד, ואיך מנוהלים קונטקסט וזיכרון, הוא "הרוטב הסודי". בגלל זה Windsurf פיתחו מודל משלהם, ו-Cursor גייסו כסף כדי לפתח מודלים.
  - **מאחורי הקלעים:** כנראה כמה סוכנים וכמה מודלים. למשל Gemini 2.5 Flash עם קונטקסט ענק מסכם את ה-codebase ל-Claude, שהוא יקר.
  - **Claude Code:** ב-Anthropic סיפרו לו ש-**95% מהמהנדסים** שלהם משתמשים ב-Claude Code (התחיל ככלי פנימי). "מי שמפתח את המודל יודע הכי טוב לבנות לו כלים". עדיף בעיקר ב-codebases גדולים. יש לו מצב אוטומטי שממשיך עד שהמשימה גמורה, והוא כותב ומריץ בדיקות. ה-background agents של Cursor 1.0 הם המתחרה הישיר.
- **ה-setup המועדף:** Claude Code מוצמד למעלה משמאל בתוך Cursor, טרמינל מתחת, וצ'אט Cursor (Claude 4) לשאלות ולהבנת הקוד. Claude Code הוא ה"מבצע". "לא להריץ אותו לבד בטרמינל אם אתם vibe coders. זה מבלבל".
- **ההדגמה:** אפליקציה ש-Mickey בנה בערך ב-4 שעות (שעתיים ביום, יומיים). כ-70% מהקוד נכתב ב-Claude Code, כולל "security analysis" עם סוכן שעובר על הקוד ומציע שינויים כ-PR ל-GitHub. **הטיפ:** למצוא starter template טוב, לתת ל-Claude Code לנתח את ה-codebase, ולבנות פיצ'רים.
- **סיום:** "תהנו מהכלים. לרובם יש free trial או שהם עולים כמה דולרים בחודש". בפרק הבא בונים אפליקציה עם auth ותשלומים מהתבנית.
