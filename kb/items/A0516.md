## סיכום

- **התקנה:**
  - `npm install -g @github/copilot` (macOS, Linux, Windows).
  - `brew install copilot-cli`.
  - `winget install GitHub.Copilot`.
  - מריצים `copilot`.
- **אימות:** `/login`, או **fine-grained PAT** עם הרשאת "Copilot Requests".
- **מה עושה:** כמו Claude Code או Gemini CLI. עובד עם issues ו-PRs ב-GitHub, MCP, ואישור לכל פעולה.
- **מחיר:** דורש מנוי Copilot (Pro/Pro+/Business/Enterprise). כל prompt צורך **premium requests**.
- `/feedback` לשליחת משוב.
