**מהתמלול / מהווידאו:**
- **מהתמלול:**
  - **הפתיחה:** Hermes צבר 160k כוכבים בחודשיים. הוא לא רק זוכר הכל, הוא גם משתפר ככל שמשתמשים בו.
  - **3 סוכנים בהדגמה, כולם מטלגרם:**
    - **Neo, המתכנת:** "do deep research about me and build a personal landing page using Claude Code". הוא משתמש ב-Claude Code skill, חוקר ובונה index.html. מוגדר לכתוב plan, לשאול שאלות המשך, ולהתחיל רק אחרי שה-spec ננעל.
    - **Pixel, המעצב:** skill מותאם עם ערכי המותג, שנבנה מכמה דוגמאות עיצוב. הוא מייצר דיאגרמה בסגנון ציור יד (prefill מול decode ב-LLM inference) ונשאר עקבי לעקרונות העיצוב.
    - **Deep Researcher:** סורק ריפואים, מאמרים וחדשות AI.
  - **SOUL.md** יושב בראש ה-system prompt וקובע את האישיות.
  - **זיכרון בשלוש שכבות:**
    - **Tier 1:** memory.md (עד 2,200 תווים: סביבה, קונבנציות, לקחים) ו-user.md (עד 1,375 תווים: פרופיל, העדפות, רמה). תמיד בקונטקסט.
    - **Tier 2:** היסטוריית סשנים ב-SQLite עם חיפוש וסיכום LLM.
    - **Tier 3:** ספקי זיכרון חיצוניים (8 אפשרויות, כולל knowledge graphs טמפורליים).
  - "עובדות קריטיות בזיכרון, כל השאר ניתן לחיפוש".
