## סיכום

- **Dotan כתב:** "אוטומציה".
- **String:** כלי prompt-to-agent של **Pipedream** (ראו [A0321](A0321.md)). מבוסס בערך על n8n/Pipedream workflows.
- **הדמו:**
  1. פרומפט: אייג'נט שמקבל **webhook**, קורא ל-**MCP** ליצירת תמונה, ושולח את התמונה ב**אימייל**.
  2. String בונה את ה-flow: הטריגר, אייג'נט עם גישה לשרתי MCP (בוחר כלי אופטימלי למשימה), ושליחת מייל.
  3. בבדיקה: מוסיפים **טופס** באתר (שם ואימייל) ששולח HTTP request ל-webhook. הדאטה מגיעה, נוצרת תמונה, ונשלח מייל.
- **רעיונות:** webhooks מאתרים, למשל נטישת עגלה ב-Shopify, שמפעילים תהליך. "רק היצירתיות תגביל אותנו".
