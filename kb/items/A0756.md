## סיכום

- **רעיונות:** daily status, איתור פערים ופתיחת issues, auto-triage ו-fix.
- **הגדרה:** קובץ markdown ב-`.github/workflows` שמקומפל ל-GitHub Actions (`gh aw`).
- **מודל עסקי:** Claude ו-Codex כלולים במנוי Copilot.

**מהתמלול / מהווידאו:**
- **ההדגמה הרשמית (מהתמלול):**
  1. ב-GitHub CLI מתקינים את ה-extension **GitHub Agentic Workflows**.
  2. בריפו מוסיפים workflow ראשון מה-agentics collection: **daily repo status**.
  3. בוחרים סוכן: **GitHub Copilot, Claude או Codex**. עם Copilot מוסיפים personal access token.
  4. ממזגים את ה-PR. בפנים: ה-workflow המקומפל של GitHub Actions וקובץ המקור ב-Markdown, עם front matter (triggers, הרשאות read-only, tools ו-**safe outputs** לכתיבה) ותיאור משימה בשפה טבעית ("צור issue חדש עם הדוח").
  5. בלשונית Actions רואים את הריצה.
