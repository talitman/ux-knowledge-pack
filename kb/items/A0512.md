## סיכום

- **ההיסטוריה:**
  - `/v1/completions`: פשוט ומוגבל.
  - Chat Completions: turn-based.
  - Function calling (2023).
  - Assistants API: hosted tools, אבל קשה לאמץ.
  - **`/v1/responses`** (2025): האיחוד.
- **"Agentic loop":** כמו בלש. נותנים ראיות, הוא חוקר, מתייעץ עם כלים ומדווח.
- **שמירת reasoning:** ב-Chat Completions ה-reasoning "נזרק" בכל תור. Responses "keeps the notebook open". מקבלים **TAUBench +5%** וניצול cache ו-latency טובים יותר.
- **Output items מרובים:** tool calls, structured outputs ושלבי ביניים ("receipts"). טוב לדיבוג, audit ו-UI.
- **Hosted tools:** file_search (RAG), code_interpreter, web search, computer use ו-remote MCP. בלי לבנות pipeline לבד.
- **המסר:** "This is the API we'll be building on for the years ahead". מומלץ ל-GPT-5.
